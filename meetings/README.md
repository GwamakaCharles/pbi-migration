# Meetings

This folder holds the interview guide, the notes template and the notes of each session and call.

- [`interview-guide.md`](interview-guide.md): the Stakeholder Interview Guide.
- [`meeting-notes-template.md`](meeting-notes-template.md): the template for the notes.

Make one file for each session, with the name `YYYY-MM-DD-<unit-or-entity>.md`. Do not put customer data in the notes.
